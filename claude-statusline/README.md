# Claude Code Status Line

Кастомный статус-бар для Claude Code — показывает модель, контекст, лимиты и расходы в реальном времени.

```
 Opus 4.8 | К: ◆◆◇◇◇◇◇◇◇◇ 21% (214k|1M) $0.28 | С: 215k $6.05
 .        | 5ч: ◼◻◻◻◻◻◻◻◻◻ 18% 3:02 | Н: ◔ 34% 2д12ч
 .        | Д: 5M $99 | 7д: 62M $684 | 30д: 156M $2419
```

## Быстрая установка

Отдай ссылку на этот репо своему Claude Code и скажи: **«Установи этот status line»**

Клод сам склонирует репо, поставит зависимости, скопирует скрипт, обновит настройки и проверит — всё автоматически.

## Ручная установка

```bash
# 1. Зависимости
brew install jq
npm install -g ccusage  # опционально, для строки расходов

# 2. Скопировать скрипт
cp statusline.sh ~/.claude/statusline.sh
chmod +x ~/.claude/statusline.sh

# 3. Добавить в ~/.claude/settings.json (вмержить в существующий файл)
# "statusLine": { "type": "command", "command": "bash ~/.claude/statusline.sh" }

# 4. Перезапустить Claude Code
```

## Что означает каждый элемент

### Строка 1 — Модель + Контекст + Сессия

| Элемент | Пример | Значение |
|---------|--------|----------|
| `Opus 4.8` | | Текущая модель |
| `К:` | `◆◆◇◇◇◇◇◇◇◇` | Загрузка контекстного окна (`◆` занято, `◇` свободно) |
| `21%` | | Процент использования контекста |
| `(214k\|1M)` | | (использовано токенов \| размер окна) |
| `$0.28` | | Стоимость последнего запроса |
| `С:` | `162k $6.05` | Итоги сессии: токены + стоимость |

### Строка 2 — Rate Limits (лимиты)

| Элемент | Пример | Значение |
|---------|--------|----------|
| `5ч:` | `◼◻◻◻◻◻◻◻◻◻ 18%` | 5-часовой лимит: шкала + % |
| `3:02` | | Время до сброса (часы:минуты) |
| `Н:` | `◔ 34%` | 7-дневный лимит: иконка + % |
| `2д12ч` | | Время до сброса (дни + часы) |

Иконки-пирожки: `○` ≤20% · `◔` ≤40% · `◑` ≤60% · `◕` ≤80% · `●` >80%

> Данные берутся напрямую из stdin-payload Claude Code (поле `.rate_limits.{five_hour,seven_day}`) — без API-запросов, без токена и без OAuth-скоупов. Работает на любом токене Claude, включая годовой. Если в payload лимитов нет, строка показывает `5ч: — | Н: —`.

### Строка 3 — Расходы

| Элемент | Пример | Значение |
|---------|--------|----------|
| `Д:` | `2M $35` | Токены + стоимость за сегодня |
| `7д:` | `21M $464` | За последние 7 дней |
| `30д:` | `115M $1228` | За последние 30 дней |

> Кэш 60 сек. Требуется утилита `ccusage`.

## Защита от thundering herd

`statusline.sh` рисуется на каждый тик каждой Claude-сессии. Если параллельно работают N сессий и кэш отсутствует/устарел, без защиты каждая форкнет свой `ccusage daily` (~100% CPU, длительный JSON-парсинг 30-дневного окна). На 14 параллельных сессиях после рестарта мака это даёт load avg 40+ и фактическое зависание. (Лимиты — строка 2 — больше не делают сетевых запросов: данные приходят в stdin, форкать нечего.)

Решение — `mkdir`-based atomic lock в `_bg_locked`. Только одна сессия в каждый момент времени запускает `ccusage` и обновляет кэш `expenses.json`. Остальные читают свежие данные из кэша. Stale-lock (старше 120 сек) очищается автоматически — на случай если процесс умер не снеся `trap`.

## Кастомизация

| Что | Как |
|-----|-----|
| Убрать расходы (строка 3) | Удалить блок `# LINE 3: EXPENSES` из `statusline.sh` |
| Убрать лимиты (строка 2) | Удалить блок `# LINE 2: RATE LIMITS` из `statusline.sh` |
| Изменить ширину шкалы | Последний аргумент в вызовах `bar()` (по умолчанию 10) |
| Изменить символы шкалы | Заменить fill/empty символы, напр. `'■' '□'` вместо `'◆' '◇'` |
| Удалить | Убрать `"statusLine"` из `~/.claude/settings.json`, удалить `~/.claude/statusline.sh` |

## Платформа

- **macOS**: работает из коробки
- **Linux**: все три строки работают (строка 2 читает stdin, Keychain не нужен) — только заменить `stat -f %m` → `stat -c %Y` по всему скрипту
